# Smart Study & Exam Prep Engine

A full-stack exam preparation and analytics platform built with **Java**, **Spring Boot**, and **MySQL**, designed around competitive exam patterns (SSC CGL, RRB NTPC, and GATE).

## Architecture
- **Backend:** Java 17+, Spring Boot (REST APIs, Spring Data JPA)
- **Database:** MySQL (Questions, Mock Attempts, Sectional Analytics)
- **Automation:** Python integration for daily spaced-repetition revision alerts

## Planned Modules
1. Custom Mock Test Generator & Sectional Timer
2. Negative-Marking Scoring & Cut-off Engine
3. Topic-Wise Weak-Area Analytics & Mistake Vault
